# ⚖️ LegalAid Pro – Legal Assistance Platform

A comprehensive full-stack web application designed to connect clients with verified lawyers, enabling users to submit cases, find legal advisors, and track case progress efficiently. Built using Javascript, Node.js, Express.js, and EJS.

# 📌 Problem Statement

Many people face significant challenges in accessing legal help:

- Difficulty finding trusted lawyers
- Risk of fraud and unverified legal advisors
- Lack of transparency in case progress
- Junior lawyers struggling to find clients

LegalAid Pro solves these issues by providing a trusted digital platform connecting clients and lawyers.

# 🛠️ Technology Stack

## Backend

- Node.js – JavaScript runtime
- Express.js – Web framework

## Frontend

- HTML5 – Structure

- JavaScript – Client functionality
- EJS – Template engine

## Database

- MongoDB – NoSQL database for storing user data, case details, and lawyer information
- Mongoose – MongoDB object modeling for Node.js (if used)

## Tools

- Git – Version control
- GitHub – Code repository and collaboration
- VS Code – Development environment

# 🔐 Application Architecture

LegalAid Pro follows MVC-based structure:

- Models – Data logic
- Views – UI templates (EJS)
- Controller – Business logic (Express)
